Cómo se crea el token (una vez)
  1. En GitHub, ve a Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: utilidades móvil. Caducidad: la que quieras (un año, por ejemplo).
  3. Repository access → Only select repositories → originales.
  4. Permissions → Repository permissions → Contents: Read-only. Nada más.
  5. Genera el token, cópialo y pégalo aquí. Solo se guarda en este móvil.

Si pierdes el móvil, bórralo en GitHub y deja de servir.
